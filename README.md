# 🏨 Hotel Booking Demand Analysis

## 📌 Project Overview

This project analyzes hotel booking data to understand booking patterns, cancellations, pricing, and customer behavior.

The analysis explores how cancellation rates vary across hotel types, lead time, customer types, and market segments.

## 🎯 Objectives

* Analyze hotel booking patterns.
* Investigate factors associated with cancellations.
* Explore pricing and demand trends.
* Compare customer and market segment behavior.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📊 Project Workflow

### 1. Data Loading & Exploration

* Loaded the hotel booking dataset.
* Reviewed the dataset structure, data types, and sample records.
* Examined descriptive statistics.

### 2. Data Cleaning & Preparation

* Identified missing values and duplicate records.
* Handled missing values in selected columns.
* Converted date fields and created an arrival date.
* Removed records with zero guests and negative ADR.
* Created additional features such as total guests, total nights, and estimated revenue.

### 3. Exploratory Data Analysis

* Compared cancellation rates by hotel.
* Examined cancellation patterns across lead-time categories.
* Analyzed ADR distributions by hotel.
* Compared cancellation rates across customer types and market segments.
* Explored correlations between selected numerical variables.

## 📈 Key Analysis Areas

* Hotel type
* Lead time
* Customer type
* Market segment
* Average Daily Rate (ADR)
* Booking cancellations

📁 Project Files
hotel_booking_analysis.ipynb — Complete Jupyter Notebook containing data preparation, analysis, visualizations, and findings

## 💡 Conclusion

The project explores differences in booking and cancellation patterns across several booking characteristics. The analysis provides a basis for understanding customer behavior, pricing, and hotel demand.
